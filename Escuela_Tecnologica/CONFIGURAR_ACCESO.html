Preparar claves y registrarlas en Netlify

Esta pantalla NO cambia la contraseña del sitio. Solo genera valores. Después debes copiarlos en las variables de Netlify y realizar un nuevo despliegue.

  1. Genera valores nuevos una sola vez y guarda tu contraseña.
  2. Abre tu proyecto en Netlify → Project configuration → Environment variables.
  3. Crea o edita cada variable con el nombre exacto y el valor correspondiente. Incluye el alcance Functions y el contexto Production.
  4. Guarda y ve a Deploys → Trigger deploy → Deploy project. Espera a que se publique.
  5. Abre el dominio principal e ingresa con el usuario y ADMIN_PASSWORD.

Generar otra vez crea valores distintos, pero no actualiza Netlify. No compartas capturas con los valores visibles. Esta herramienta no envía datos por internet ni los guarda; conserva tu contraseña en un gestor antes de cerrar.
